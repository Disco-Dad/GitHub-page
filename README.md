## 🚀 Overview

Dark Side of the Moon 2 is an immersive, interactive website that explores the fascinating world of lunar science and astronomy. From the mysterious far side of the Moon to the intricate dance of lunar phases, this project combines stunning visuals with educational content to create an engaging space exploration experience.

## ✨ Features

### 🌌 Interactive Elements
- **Animated Moon Phases**: Real-time lunar cycle visualization with detailed phase information
- **3D Moon Rotation**: CSS-powered 3D moon with realistic surface features and craters
- **Parallax Scrolling**: Smooth scrolling effects that create depth and immersion
- **Interactive Lunar Map**: Clickable hotspots revealing major lunar features
- **Current Moon Phase Detection**: Automatically highlights today's moon phase

### 🎨 Visual Design
- **Space-themed Animations**: Twinkling stars, moving cosmic elements
- **Gradient Typography**: Modern gradient text effects with custom fonts
- **Glass Morphism UI**: Contemporary frosted glass design elements
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Dark Theme**: Eye-friendly space-themed color palette

### 📚 Educational Content
- **Lunar Science Facts**: Comprehensive information about Moon formation and characteristics
- **Phase Explanations**: Detailed descriptions of each lunar phase with durations
- **Historical Context**: Space exploration milestones and discoveries
- **Interactive Statistics**: Key lunar measurements and orbital data

## 🛠 Technology Stack

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Advanced animations, transitions, and responsive design
- **Vanilla JavaScript**: Interactive features and dynamic content
- **Google Fonts**: Orbitron and Space Mono typography
- **GitHub Pages**: Static site hosting and deployment

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/dark-side-of-moon-2.git
   cd dark-side-of-moon-2
   ```

2. **Open locally**
   ```bash
   # Simple local server (optional)
   python -m http.server 8000
   # Or just open index.html in your browser
   open index.html
   ```

3. **GitHub Pages Deployment**
   - Push to GitHub
   - Enable GitHub Pages in repository settings
   - Select main branch as source
   - Access via `https://yourusername.github.io/dark-side-of-moon-2`
